연결 설정이 아직 안 됐습니다

이 관리자 페이지는 Supabase 프로젝트에 연결되어 동작합니다. assets/js/db.js 의 URL 과 KEY 가 비어 있습니다.

  1. Supabase 프로젝트 생성 후 backend/schema.sql 을 SQL Editor 에서 실행
  2. Authentication > Users 에서 관리자 계정 추가 (schema.sql 의 is_admin() 에 적힌 이메일)
  3. Project Settings > API 의 URL 과 anon/publishable key 를 db.js 에 입력

자세한 순서는 backend/SETUP.md 를 참고하세요.
